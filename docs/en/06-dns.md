# DNS

DNS, or the Domain Name System, translates human-readable website names like example.com into the numeric IP addresses computers use to locate each other. When you type a web address into a browser, a DNS resolver looks up the corresponding IP address before your device can connect to the server. This system works like a phone book for the internet, making it unnecessary to memorize numeric addresses.
