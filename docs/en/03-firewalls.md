# Firewalls

A firewall is a network security system that monitors and controls incoming and outgoing traffic based on a set of rules. It acts as a barrier between a trusted internal network and untrusted external networks like the internet, blocking connections that don't match its allowed criteria. Firewalls can be hardware devices, software running on a server, or built into a router.
