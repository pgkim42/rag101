# How solar panels work

Solar panels generate electricity using photovoltaic cells that convert sunlight directly into electrical current. When photons from sunlight strike the silicon layers inside a cell, they knock electrons loose, creating a flow of electricity. This direct current is then usually converted to alternating current by an inverter so it can power homes and feed into the electrical grid.
