# VPN

VPN, 즉 가상 사설망은 기기와 원격 서버 사이에 암호화된 통로를 만들어, 실제 IP 주소를 가리고 인터넷 제공자나 같은 네트워크의 다른 사람이 통신 내용을 읽지 못하게 한다. 지역 제한 콘텐츠를 보거나, 공공 와이파이에서 데이터를 지키거나, 원격 근무 중에 회사 내부 네트워크에 안전하게 접속할 때 흔히 쓴다. VPN은 어떤 데이터를 보내는지 숨기지만, 온라인에서 완전히 익명이 되게 하지는 않는다.
