# HTTP와 HTTPS

HTTP와 HTTPS는 모두 웹 브라우저와 서버 사이에서 데이터를 주고받는 규약이지만, HTTPS는 TLS로 암호화를 한 겹 더한다. 이 암호화는 전송 중인 데이터를 제삼자가 읽거나 건드리지 못하게 막으며, 비밀번호와 결제 정보 같은 민감한 내용을 지키는 데 필수다. 요즘 브라우저 대부분은 일반 HTTP 사이트를 "안전하지 않음"으로 표시해 HTTPS 사용을 권한다.
