# C장 해설

> 먼저 [C장 ⑩](../C-vectors.md)의 문제에 스스로 답을 적은 다음 읽자.

## 1. 정규화와 내적

```text
cos(a, b) = (a · b) / (|a| × |b|)
|a| = |b| = 1  이면  cos(a, b) = (a · b) / 1 = a · b
```

정규화하지 않고 내적으로 검색하면 **길이가 긴 문서 벡터**가 유리하다. 내적 = |a| × |b| × cos θ라서, 방향이 조금 덜 맞아도 길이가 크면 이긴다(C장 6.3의 B = (5, 1)). 이 모델의 평균 풀링 벡터는 문장마다 길이가 다르니(예: 5.044), `normalize_embeddings=True`를 빼면 길이라는 엉뚱한 요인이 순위에 섞인다.

## 2. 「배를 타고 바다로 나갔다」로 세 가지 구분

- **토큰 임베딩**: 표에서 꺼낸 `▁배`의 행. 「배를 깎아 먹었다」의 `▁배`와 완전히 같다(코사인 1.000 [측정]). 문맥을 모른다.
- **문맥 토큰 표현**: 12층을 지난 뒤 `▁배` 자리의 384개. `▁타고`, `▁바다`의 정보가 섞였다. 「먹는 배」의 `▁배`와 코사인 0.933 [측정]. 문맥을 안다.
- **문장 임베딩**: 이 문장의 조각 10개(`<s>`부터 `</s>`까지)의 문맥 표현을 평균 내고 길이 1로 만든 벡터 하나. 「배」 하나가 아니라 문장 전체를 대표한다.

## 3. 「코사인 0.834면 답이 있을 확률이 83.4%」

오류 1: **코사인은 확률이 아니다.** 두 벡터의 각도의 코사인일 뿐이고, 0.834라는 값의 크기는 모델과 데이터에 따라 뜻이 다르다. 같은 질문 안에서 문서들의 순서를 비교하는 데만 의미가 있다.

오류 2: **코사인은 「답이 있음」을 재지 않는다.** 이 모델은 비슷한 이야기를 하는 문장끼리 가깝게 학습됐다. 실제로 「DNS 서버 주소는 어떻게 바꾸나?」와 DNS 설명 문장은 0.834였지만, 그 문장에는 답이 없다 [측정].

## 4. q = (0, 2), A = (0, 1), B = (3, 3)

```text
내적:  q·A = 0×0 + 2×1 = 2          q·B = 0×3 + 2×3 = 6          → B가 1등
길이:  |q| = 2, |A| = 1, |B| = √18 = 4.2426
코사인: cos(q,A) = 2 / (2 × 1) = 1.0  cos(q,B) = 6 / (2 × 4.2426) = 0.7071  → A가 1등
```

A는 q와 방향이 완전히 같다(둘 다 위쪽). B는 45도 기울었지만 길어서 내적으로는 이긴다. [측정, 해설용 계산과 일치]

## 5. 배율을 20 대신 1로

정답을 고를 확률이 **커진다**. 0.119 → 0.360 [측정, 해설용 계산].

```text
배율 1:  e^0.5 / (e^0.5 + e^0.6 + e^0.1) = 1.649 / (1.649 + 1.822 + 1.105) = 0.360
```

배율이 작으면 소프트맥스가 평평해져 세 후보의 확률이 1/3 근처로 모인다. 오답이 더 가까운데도 정답 확률이 0.36이나 되니, 손실(−ln 0.360 = 1.02)이 작아져 학습 신호가 약해진다. 반대로 정답이 훨씬 가까워도 배율 1로는 확률을 크게 만들 수 없다. 코사인은 −1~1 범위라, 정답 코사인 1, 오답 둘이 −1이어도 e¹ / (e¹ + 2e⁻¹) = 0.787이 최대다. 그래서 코사인에 큰 배율(온도의 역수)을 곱해 「확실한 구분」을 가능하게 한다. 배율은 「얼마나 날카롭게 구분하라고 요구할지」를 정하는 다이얼이다.

## 6. 문장 쌍 추가

이 문제는 정답이 정해져 있지 않다. 직접 돌려서 예측과 비교하는 것이 목적이다. 다만 원리상 예상할 수 있는 것:

- **한국어-영어 번역쌍**: 이 모델은 번역쌍이 같은 벡터를 내도록 학습했으므로(C장 6.9의 지식 증류) 높게 나올 것으로 예상된다.
- **오타 하나**: 토큰화가 달라진다(오타 낱말이 다른 조각으로 쪼개짐). 짧은 문장일수록 영향이 크다.
- **존댓말/반말**: 뜻이 같고 어미만 다르다. 높게 나올 것으로 예상된다.

예측이 틀린 쌍이 있다면, `tokenizer.convert_ids_to_tokens()`로 두 문장의 조각을 비교해 보자. 조각이 얼마나 달라졌는지가 많은 것을 설명한다.
